# MACD

 **Efficient Multi-Agent Cooperative Strategy Learning via Curriculum Decomposition in Policy Distillation**.

## Introduction

MACD is a plug-and-play multi-agent reinforcement learning framework for cooperative tasks under the CTDE paradigm. It transfers cooperative knowledge from communication-based teacher agents to decentralized student agents through policy distillation. To reduce the negative impact of policy discrepancies, MACD introduces a Curriculum Decomposition Module (CDM), which partitions teacher knowledge into curricula and gradually shifts training from distillation-guided learning to self-learning.
